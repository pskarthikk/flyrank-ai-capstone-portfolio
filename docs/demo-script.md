# 3–5 minute demo script

## 0:00–0:30 — The claim

“Hi, I’m Karthikk. This is my AI/ML portfolio. The idea is simple: instead of only saying I can work with AI and machine learning, I want the site to show the work, a working feature, and the decisions behind it.”

Show the hero and the selected-work section.

## 0:30–1:45 — The real case

Open the FlyRank ML Internship case.

Say:

“The main case is my Refresh / Content Opportunity Scoring work. The problem was prioritizing content pages for review. In the starter experiment I compared a hand-written rule with machine-learning models and evaluated the ranking using Precision@K.”

Point to:
- 30,000 content items
- 16,262 declining pages
- Random Forest Precision@50 = 0.740
- Hand-written rule Precision@50 = 0.240

Open the linked project/paper briefly if useful.

## 1:45–2:45 — Run the feature

Scroll to Content Review Priority Playground.

Move the sliders.

Say:

“This is a small working browser demo of the decision logic. It reacts immediately to traffic trend, click trend, rank change and content age.”

Change values so the score moves between low, medium and high priority.

Important:

“This is intentionally not presented as the trained Random Forest. It is a transparent demo of the reasoning behind a review-priority score.”

## 2:45–3:30 — Where AI helped

Show the Honest Story / How this was built sections.

Say:

“AI helped me most as a development partner: breaking vague ideas into steps, explaining implementation details, iterating on the interface, and helping me write and review the project. But I still had to decide what the portfolio should prove and verify the actual evidence.”

## 3:30–4:15 — What broke and what comes next

Say:

“One thing I caught was that a working score calculator could be mistaken for the actual trained model. I fixed that by making the boundary explicit.”

Then show the next-case plan.

“The next case is my FlyRank ML Internship Capstone — Content Opportunity Scoring. I’ll add it using the same three beats: Problem, What I did, What came of it.”

## 4:15–4:30 — Close

“When someone asks whether I can actually build with AI, this is the link I can send.”
